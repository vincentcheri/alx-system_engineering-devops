## 📡 OSI Model — Layers 1 to 7

| Layer | Name | Function |
|-------|------|----------|
| **7** | **Application** | Applications create the data (HTTP, FTP, SMTP, DNS) |
| **6** | **Presentation** | Data is formatted, encrypted, and compressed (SSL/TLS, JPEG, MPEG) |
| **5** | **Session** | Connections are established, managed, and terminated (NetBIOS, RPC) |
| **4** | **Transport** | Data is broken into segments for reliable delivery (TCP, UDP) |
| **3** | **Network** | Segments are packaged into packets and routed (IP, ICMP, RIP) |
| **2** | **Data Link** | Packets are framed and sent to the next device (Ethernet, MAC, PPP) |
| **1** | **Physical** | Frames are converted into bits and transmitted physically (Cables, Radio, Fiber) |
