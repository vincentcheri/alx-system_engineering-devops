🚀 My DevOps & System Engineering Journey
🐚 Shell Fundamentals
Shell Basics → Navigating, manipulating files, and running commands like a pro.

Shell Permissions → Managing users, groups, and file permissions (chmod, chown, sudo).

Shell Redirections → Piping, redirecting stdin/stdout/stderr for powerful command chaining.

Shell Variables & Expansion → Using environment variables, parameter expansion, and command substitution.

🔁 Scripting & Automation
Loops, Conditions, Parsing → Automating repetitive tasks with bash scripting (if, for, while, case).

Processes & Signals → Managing running processes (ps, kill, bg, fg) and handling signals (SIGTERM, SIGKILL).

🌐 Networking & Web Infrastructure
Regex → Pattern matching for filtering logs, validating input, and parsing text.

Networking Basics (TCP/IP) → Understanding layers, ports, IPs, and how data travels.

Networking Basics Part 2 → Deep dive into DNS, DHCP, and routing.

Web Infrastructure Design → Designing scalable, secure, and reliable web architectures.

⚙️ Configuration Management
SSH → Securely connecting to remote servers and automating logins with keys.

Configuration Management (Puppet) → Writing manifests to enforce desired system states.

🌍 Web Servers & Load Balancing
Web Server (Nginx) → Configuring Nginx for static content, reverse proxying, and custom headers.

Load Balancer (HAProxy) → Distributing traffic across multiple backends for high availability.

🛠️ Web Stack Debugging
Web Stack Debugging 0 & 1 → Troubleshooting common web server issues: ports, configs, processes, and logs.
